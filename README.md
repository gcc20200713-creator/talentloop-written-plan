# TalentLoop · AI 招聘 Agent 产品方案

**v1.0** · [阅读产品方案](https://gcc20200713-creator.github.io/talentloop-written-plan/) · [体验交互 Demo](https://talentloop-mvp-ccg.fresh-stork-7604.chatgpt.site/)

TalentLoop 面向负责实习与校招初筛的企业 HR。产品从岗位要求出发，在企业已有简历库中检索候选人，并把推荐理由关联到简历原文。HR 核对证据后决定是否推荐给评估官。

方案页包含用户与切入点、核心功能、产品取舍、筛选流程、效果验证设计和 AI 使用说明。交互 Demo 以 AI 产品经理岗位为例，独立托管于 ChatGPT Sites。

本仓库的 `index.html` 是方案站的入口。GitHub Pages 从 `main` 分支根目录发布。
